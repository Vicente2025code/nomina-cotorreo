# mis-habilidades

Colección personal de habilidades (skills) para Claude Code, más sub-proyectos varios.

## Contenido

### `.claude/skills/` — Habilidades de Claude

40 marketing skills instaladas desde [coreyhaines31/marketingskills](https://github.com/coreyhaines31/marketingskills):
CRO, copywriting, SEO, ads, cold-email, churn-prevention, pricing, referrals,
revops, sales-enablement, customer-research, ad-creative, analytics, ASO, y más.

Claude las carga automáticamente cuando hagas preguntas relevantes (conversión,
copy, SEO, growth, etc.) en este repo.

### `nomina/` — Procesador de Nómina Grupo Cotorreo

Sistema que toma reportes de relojes checadores y prellena el Excel de nómina
quincenal. Ver [`nomina/README.md`](nomina/README.md) para detalles de uso.

### `videos/pauline/` — Video despedida para Pauline

Proyecto Remotion (vertical 9:16, ~4:30, música de Coldplay) para regalarle a
Pauline al cierre de su intercambio de 10 meses en Ciudad Quesada. Ver
[`videos/pauline/README.md`](videos/pauline/README.md) para cómo correrlo.
